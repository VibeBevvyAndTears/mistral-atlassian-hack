## Project
- **Name**: Conve
- **Type**: B2B SaaS - cross-team communication workspace (channels, conflicts, suggestions)
- **Languages**: English only (latin system stack; no CJK font requirement)
- **Former internal label**: Cross-Team (retire in UI copy)

## Target Audience
- **Role**: Team leads, ops, PMs coordinating across org teams
- **Tech level**: High; daily Slack/Teams/Linear users
- **Age range**: 25-45
- **Context**: Desk work, laptop-first; mobile for triage

## Brand Personality
- Professional, calm, operational
- Clarity over flourish; trust through structure

## Aesthetic Direction
- **Chosen**: Direction A - Mockup Faithful
- Dark workspace (mockup is source of truth)
- Dense feed + persistent left nav + top search
- Accents: Signal Red for review urgency; Ask Violet for AI / bell / Ask AI only (no page-wide purple gradients)

## Accessibility
- WCAG 2.2 AA minimum
- Keyboard-first nav for sidebar + filters
- `prefers-reduced-motion` respected

## Reference Sites
- User-supplied channel mockup (dark Slack/Teams hybrid) - primary visual reference
- Structural kinship: Slack (sidebar IA), Linear (density/calm), Teams (org/team nesting)
